# Universal AI Tutor — Beta 0.1

Released October 17, 2026. This is a reusable teaching skill, not an app. Teaching behavior is being evaluated; AI explanations and grading can be mistaken.

## Start in an ordinary AI chat

Attach or paste the complete `UNIVERSAL-AI-TUTOR-PORTABLE.md` file. If you received only the ZIP, extract it and attach `SKILL.md` plus `references/learner-record.md` instead. Then send:

> Use these tutoring instructions. I want to learn [subject] so I can [goal]. Teach the concepts and why they work, then guide me one question at a time.

## Start in a tool that supports skills

Extract the ZIP and add the entire `universal-ai-tutor` folder using your tool's supported skill installation method. Then ask it to use `universal-ai-tutor`. Installation steps vary by tool; this package does not install itself.

## Add your course material

Attach slides, notes, past exams, homework, or rubrics. Say what you are studying and any deadline. For example:

> Teach me from these biology slides and use the past exam to guide fresh practice. My exam is next Friday.

The tutor should identify what it can actually read. If a file is unreadable, provide a readable export or excerpt. File access and audio/image capabilities depend on your AI tool.

## Steer the lesson

You can say “Explain why,” “I'm lost,” “Give me practice,” “Quiz me,” or “Skip this detour.” The tutor leads by default, but you can redirect it. Skipped foundations remain unresolved rather than being marked mastered.

## Save and resume

Before changing chats, ask: “Give me a portable learner record.” Save that separate record, then provide it with the tutor instructions in the next chat. Reattach any course files needed there. Cross-chat memory and reminders are not automatic. Keep your completed work and personal learning record out of the reusable skill folder you share with others.

## Beta feedback

The tutor may optionally ask what still feels unclear at a natural stopping point. To report a problem to the person who shared this skill, include **Beta 0.1**, the AI tool/model if known, the subject, what you expected, and a short relevant exchange you are comfortable sharing. Feedback is not collected or sent automatically.
