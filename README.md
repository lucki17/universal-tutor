# Universal AI Tutor

A portable AI tutoring skill for learning from course slides, notes, homework, and past exams.

## Try Beta 0.1

For an ordinary AI chat, attach or paste [the portable tutor](UNIVERSAL-AI-TUTOR-PORTABLE.md). For a tool that supports skills, use [the ZIP package](universal-ai-tutor.zip). Follow the [getting started guide](universal-ai-tutor/GETTING-STARTED.md) or [sharing instructions](SHARING-INSTRUCTIONS.md).

The tutor explains concepts and their foundations, leads one question at a time, adapts practice, and revisits earlier learning. Subject modes cover mathematics, sciences, humanities, languages, programming, and more. Learners can interrupt or redirect lessons, including recommended prerequisite detours.

## Beta status

Released October 17, 2026. Package structure has been checked; teaching quality and learning outcomes still need real learner testing. This skill depends on the receiving AI tool for file reading and answer quality. It does not provide automatic cross-chat memory or reminders.

For feedback, include the beta version, AI tool/model if known, subject, expected behavior, and a short exchange you choose to share. Feedback is not automatically collected.
